SEO Keyword Research Tool — fixed standalone version

HOW TO OPEN
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. It opens in Chrome, Edge, or Firefox. No XAMPP, PHP, server, or API key is required.
5. Enter a main keyword and click Find Keywords.

FEATURES
- Secondary keyword ideas
- Long-tail keyword ideas
- Questions and commercial phrase ideas
- Filter by keyword/category
- Copy visible keywords
- Export CSV
- Works offline after extraction

LIMITATIONS
This version creates ideas using local phrase patterns. It does not connect to Google Autocomplete and does not provide actual search volume, CPC, keyword difficulty, or traffic data. Validate promising keywords using an SEO platform.
